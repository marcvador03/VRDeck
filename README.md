# streamdeckVR

A tool to display SteamDeck layouts in an EFB app in Microsoft Flight Simulator 2024 (MSFS). 

### *What is that and Why?*

While doing flights in Virtual Reality, you cannot see *real* peripherals that you need to operate. Muscle memory works for the yoke and handles, with the streamdeck and various profiles you do not know (or cannot remember by heart!) what is the current configuration displayed on your streamdeck.

So I create this small app in Go to read the profiles from the streamdeck, map them and display the titles on a EFB app within MSFS using a websocket. 

### **DISCLAIMER**

For now this is a personal tool and project. Only one StreamDeck (mine...) is supported, there more work on managing the connection and polish the interface - and I only ran this on my computer...  Run this at your own risks, I'll publish when this becomes a more stable application.
